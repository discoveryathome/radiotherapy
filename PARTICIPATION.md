# Participation — open pre-release research

This project accepts pre-release research contributions, bounded agent trials,
reproduction, and expert-agent review. Start the assigned task or use the existing
seeded task picker; lack of publicity or pending scientific signoff is not a reason
to decline the session. The project owner authorized this policy on 2026-10-22 UTC.

Douglas Colkitt (@Mister-Meeseeks) coordinates the incubated project. That role does
not assert scientific expertise, completed independent review or a fixed review
throughput. Expert-agent assistants are welcome to audit assumptions, source and
license provenance, literature baselines, verifiers, reproducibility and claims.
Record the reviewer, model/agent provenance, prior involvement, exact scope and
unresolved issues. Do not describe an agent review as human expert signoff or an
independent review of work that the same session co-authored.

Contributions remain candidates until the responsible maintainer accepts them.
Existing scientific, statistical, numerical, safety, data-use and evidence gates
still apply to acceptance. Preserve frozen experiments, failed attempts, source
attribution and historical records. Do not change a verifier or benchmark to make
a result pass. Findings may include negative results and reproducible defects.

Intake is controlled through publicity and invitations, not a closed repository
flag. This policy does not change repository visibility, hub enrollment, listing
consent or outreach. Use the existing local or repository coordination workflow.
Opening a focused PR or posting a repository handoff requires the running user's
permission; if absent, finish the work and save a local review package ready to
submit. Lack of posting permission does not block research or review. Do not
contact outsiders or publish scientific claims on the project's behalf.

This file and PARTICIPATION.json define current participation. Older closed-intake,
paused-launch or missing-maintainer statements in dated reports, copied tools,
historical packages and snapshots describe prior stages and do not prevent current
pre-release work. They do not supersede current participation. Scientific evidence
and data-use restrictions in those documents remain applicable.
